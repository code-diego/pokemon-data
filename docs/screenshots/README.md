# Screenshots

Carpeta para las capturas del dashboard. Una vez que el proyecto esté desplegado:

## Capturas sugeridas

| Archivo | Página | Qué mostrar |
|---------|--------|-------------|
| `main.png` | Vista general | Filtros activos, KPIs, gráfica de tipos |
| `comparador.png` | Comparador | 3-4 Pokémon con radar y tarjetas coloreadas |
| `pokedex.png` | Pokédex | Ficha de un Pokémon icónico (ej. Charizard) |
| `cobertura.png` | Cobertura de tipos | Grid de botones coloreados, modo ofensivo |
| `analisis.png` | Análisis estadístico | Tab BST por tipo con boxplot |

## Cómo tomarlas

```bash
# Con el dashboard corriendo en localhost:8501
# En Linux: usar Flameshot, GNOME Screenshot o Spectacle
# Resolución recomendada: 1280×800 o superior
# Formato: PNG (sin JPEG, para evitar artefactos en texto)
```

## Demo GIF (opcional pero recomendado)

Herramientas para grabar GIF del flujo principal (~15 seg):
- **Peek** (Linux): `sudo dnf install peek`
- **Kooha** (GNOME): disponible en Flathub

Guardar como `demo.gif` en esta carpeta y referenciar en el README principal.
